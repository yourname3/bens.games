ben's bales is a short platformer game made for the Virginia Collegiate Game Jam.

The goal with this game was to implement 3D skinned armature animation in a C
game engine, targetting WebGL 1. The idea was that WebGL 1 should make a good
target for certain games as it is very widely available.
